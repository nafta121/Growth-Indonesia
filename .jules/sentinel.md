## 2023-10-25 - [Path Traversal in Markdown Dynamic Routes]
**Vulnerability:** A path traversal vulnerability existed in `lib/mdx.ts` where unsanitized user input (slug) was directly joined with `path.join` and passed to `fs.readFileSync`. This allowed attackers to read arbitrary files from the filesystem via the API endpoint `app/api/markdown/route.ts` which took the path directly from URL parameters.
**Learning:** `path.join` does not inherently block `../` traversals, and dynamic content endpoints reading from filesystem must forcefully sanitize slugs. Relying only on Next.js `[slug]` router validation is insufficient if utility functions are exported and used elsewhere like in API routes.
**Prevention:** Always strip non-alphanumeric/hyphen/underscore characters using regex like `replace(/[^a-zA-Z0-9-_]/g, '')` for file names/slugs before filesystem operations, or verify that the resolved path still starts with the base directory constraint using `path.resolve` and `startsWith`.
